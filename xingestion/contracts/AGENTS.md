# Capability contract artifacts

This directory contains machine-readable, protocol-neutral product capability
contracts owned by `techtiesai-png/XINGESTIONV2`.

Contracts may define stable capability IDs, input/output expectations,
fidelity, pagination and provenance requirements. They must never contain X
operation/query IDs, feature bundles, browser selectors, Twikit/twscrape types,
session secrets or provider-specific request construction.

Changes are versioned and must remain compatible with X-rev
`ProtocolCapabilityBinding` declarations. Update `plan.md` and
`implemented.md` when contract behavior or compatibility changes.
